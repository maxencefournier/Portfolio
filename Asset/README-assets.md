# Fichiers à ajouter

Dépose ici tes propres fichiers, en gardant exactement ces noms
(ou modifie les chemins correspondants dans `index.html`) :

- `video/showreel.mp4` → ta vidéo d'intro (courte, quelques Mo max, format .mp4)
- `images/hero-poster.jpg` → une image fixe affichée pendant le chargement de la vidéo
- `images/mondes-disparus.jpg` → un visuel du projet Mondes disparus
- `images/pirate-cinematic.jpg` → un visuel du projet Pirate Ship Cinematic

Conseils :
- Compresse la vidéo (HandBrake, ou export H.264 léger) pour qu'elle charge vite : viser < 8-10 Mo.
- Les images en .jpg ou .webp, largeur ~2000px suffit pour du plein écran.
